# Prometheon 🚀

A learning platform for mastering software engineering through ancient wisdom and modern code.

## 🎯 Project Overview

Prometheon is a React-based learning platform where users can:
- Explore Sacred Texts (learning materials)
- Complete Tasks & Challenges
- Track progress through 7 mythical realms
- Earn achievements and points

## 📚 Learning Approach

This project is designed as a **hands-on React learning experience**. You'll build real features while learning React concepts step by step.

**Start here**: Read `Docs/06-Learning-Roadmap.md` for your step-by-step guide!

## 🛠️ Tech Stack

- **React 18+** with TypeScript
- **Vite** for fast development
- **Tailwind CSS** for styling
- **React Router** for navigation
- **Zustand** for state management
- **TanStack Query** for data fetching

See `Docs/01-Technology-Stack.md` for full details.

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (LTS recommended)
- npm, pnpm, or yarn

### Installation

```bash
# Install dependencies
pnpm install
# or
npm install

# Start development server
pnpm dev
# or
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Available Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm preview` - Preview production build
- `pnpm lint` - Run ESLint
- `pnpm format` - Format code with Prettier
- `pnpm type-check` - Check TypeScript types
